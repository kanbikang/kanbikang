# 출퇴근 기록 앱 (Android)

홈 화면 위젯의 **[출근] [퇴근]** 버튼 한 번으로 시각을 기록하는 안드로이드 앱입니다.
인터넷·로그인·권한이 필요 없고, 모든 기록은 폰 안(Room DB)에만 저장됩니다.

## 기능

- 홈 화면 위젯: [출근] [퇴근] 큰 버튼 2개, 오늘 출근/퇴근 시각 표시, 누르면 "출근 08:52 저장" 알림
- 실수 방지: 같은 날 출근은 첫 기록 유지, 퇴근은 마지막 시각으로 갱신, 자정 넘긴 퇴근은 전날 출근에 연결
- 앱 화면: 날짜 / 출근 / 퇴근 / 근무시간 목록, 기록 수동 추가·수정·삭제, 이번 달 근무일수·총 근무시간
- 내보내기: 월별 CSV(엑셀에서 열림)를 카톡·메일 등으로 공유

## APK 내려받기

GitHub Actions가 푸시할 때마다 디버그 APK를 빌드해 **Releases**의 `debug-latest`에 올립니다.

- 최신 APK: https://github.com/kanbikang/kanbikang/releases/tag/debug-latest → `attendance-debug.apk`

## 폰(갤럭시 Z 플립7)에 설치하기

1. 폰의 인터넷(삼성 인터넷 또는 Chrome)으로 위 Releases 주소를 열고 `attendance-debug.apk`를 누릅니다.
   (저장소가 비공개라면 GitHub에 로그인한 상태여야 합니다.)
2. "이 유형의 파일은 휴대전화를 손상시킬 수 있습니다" 안내가 나오면 **다운로드**를 누릅니다.
3. 알림창 또는 `내 파일 > 다운로드`에서 `attendance-debug.apk`를 누릅니다.
4. "보안상의 이유로 출처를 알 수 없는 앱을 설치할 수 없습니다" 창이 뜨면 **설정**을 누르고,
   해당 앱(인터넷 브라우저 또는 내 파일)의 **이 출처 허용**을 켠 뒤 뒤로 갑니다.
5. **설치**를 누릅니다. "Play 프로텍트" 경고가 나오면 **무시하고 설치** 또는 **자세히 보기 → 설치**를 누릅니다.
6. 설치가 끝나면 **열기**를 눌러 앱이 뜨는지 확인합니다.

카톡으로 보내서 설치하는 방법: 컴퓨터에서 APK를 받아 카카오톡 "나와의 채팅"에 파일로 보낸 뒤,
폰에서 그 파일을 눌러 저장하고 `내 파일 > 다운로드`에서 열면 4~6단계와 같습니다.

## 홈 화면에 위젯 추가하기

1. 홈 화면의 빈 곳을 길게 누릅니다.
2. 아래에 나오는 **위젯**을 누릅니다.
3. 목록에서 **출퇴근 기록**을 찾아 누르고(검색창에 "출퇴근" 입력 가능), 위젯을 길게 눌러 홈 화면에 놓거나 **추가**를 누릅니다.
4. 위젯의 [출근] [퇴근] 버튼을 누르면 바로 기록됩니다. 위젯 위쪽의 날짜/시각 부분을 누르면 앱이 열립니다.

## 개발 정보

- Kotlin, Jetpack Compose, Room, Jetpack Glance / minSdk 26, targetSdk 35
- 빌드: Gradle 8.11.1, JDK 17에서 `gradle assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`
- `keystore/debug.keystore.b64`는 CI에서 매번 같은 서명으로 빌드해 재설치(업데이트)가 되도록 넣어 둔 디버그 전용 키입니다.
